Enregistrer un étudiant

Ajoute un étudiant dans la collection etudiants pour le tarif étudiant.
Le numéro étudiant est généré automatiquement au format : UNIV-XX-1234.

Inviter un agent

L’agent recevra une invitation par e-mail. Il définira lui-même son mot de passe : aucun mot de passe n’est conservé dans la base métier.

📂 Gestion des billets CSV

Import de billets

Importer des billets d’entrée ou des billets internes depuis un fichier CSV.

Pour les billets d'entrée : numero_billet;type_acces;prix;tarif_universite;statut
Pour les billets internes : numero_billet;type_billet;prix
